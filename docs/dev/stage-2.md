# Этап 2: арена с графикой

**Вопрос этапа:** понятно ли за полсекунды, что происходит на экране, и приятно ли управлять героем? (См. [../14-prototype-plan.md](../14-prototype-plan.md).)

Результат — игра в браузере: арена, три героя, ты против неподвижного («AFK») врага. Бота нет. Сети нет.

## Решения автора для этого этапа

- **Герои:** Хронист, Тень-без-часов, Мясник ([../07-heroes.md](../07-heroes.md)).
- **Противник:** герой, который просто стоит («AFK»). Логику бота не писать.
- **Цель матча:** уничтожить вражеский трон ([../15-match-goals.md](../15-match-goals.md)). Условия победы делаются общим механизмом, чтобы позже добавить цели кампании.

## Что сделать

### 1. Доработки ядра и содержимого

- [ ] **Команды.** Служебное поле `team` у сущности. **Законы его не читают** (лорная честность: закон бьёт всех). Команду читают только условия победы, интерфейс и будущая мутация избирательности.
- [ ] **Условия победы.** В `core`: интерфейс `VictoryCondition` — функция `(world) => результат | null`, проверяется каждый тик после всех систем. При срабатывании — событие в журнале и остановка матча. В `content`: условие «трон уничтожен».
- [ ] **Трон.** Сущность в `content`: `Structure`, `Material`, `Atomic`, `InTime`, `Mindless`, `Nonflammable`, `Mass:Huge`, `Terrain`. Здоровье — на усмотрение (запиши в `decisions.md`).
- [ ] **Закон L7-02 «Остановка времени»** по [../04-laws-catalog.md](../04-laws-catalog.md) и [../06-time-system.md](../06-time-system.md). Прокачки ещё нет, поэтому на этом этапе Хронист получает его сразу как отдельный закон (пометить в коде как временное).
- [ ] **Законы Мясника:** L1-01 «Перелом» и L1-02 «Кровотечение» по каталогу. Кровотечение теряет здоровье **при движении**, оставляет кровавый след на клетках.
- [ ] **Особое взаимодействие «Пламя + Кровотечение = прижигание»** из [../05-interactions.md](../05-interactions.md). Это первое настоящее особое взаимодействие: оно живёт в `content/interactions.ts`.
- [ ] **Герои** в `content/heroes/`: по файлу на героя, по шаблону из [../07-heroes.md](../07-heroes.md): метки, законы, лорный ресурс и его восстановление, слабости, цена силы.
  - Хронист: «Хронос» восстанавливается быстрее, когда он стоит на месте; хрупкое тело (зоны теряют целостность на 30% быстрее); законы L7-01, L7-02.
  - Тень-без-часов: `OutOfTime`, `Mass:Light`; законы L2-02, L1-02.
  - Мясник: `IronWill`, `Regenerating`, `Mass:Heavy`; законы L1-01, L1-02, L2-01.
  - У каждого базовая атака — закон (сейчас это L2-00 «Удар»).
- [ ] Тесты на всё новое по [testing.md](testing.md).

### 2. Клиент (`apps/client`)

Стек: **Vite + PixiJS** ([stack.md](stack.md)). Клиент — тонкий слой: вся логика в `core`, клиент только рисует мир и превращает ввод в команды.

- [ ] **Цикл игры:** симуляция идёт фиксированными тиками (30/с) через аккумулятор; отрисовка — с интерполяцией между тиками.
- [ ] **Экран выбора:** выбрать героев своей команды и героя-врага. Враг стоит у своего трона.
- [ ] **Управление своей командой:** игрок управляет всеми героями своей команды и переключается между ними клавишами `1`, `2`, `3` (как отрядами в стратегиях). Это тестовый режим: так можно в одиночку собрать «стену ножей» Хронистом и Тенью.
- [ ] **Управление** по [../10-controls.md](../10-controls.md): ПКМ — идти/атаковать, Q/W/E/R — законы героя, Shift + действие — добавить в план, Tab (удерживать) — метки сущности под курсором.
- [ ] **Карта-арена:** одна небольшая арена, которая целиком помещается на экран (камера без прокрутки). Есть вода, трава, деревья, камни, по трону на каждом краю.
- [ ] **Визуальный язык** по [../10-controls.md](../10-controls.md), «Читаемость законов»: цвет и форма эффекта по уровню абстракции. Графика — простые фигуры, без спрайтов.
- [ ] **Время на экране:** сущности с `clock.rate < 1` обесцвечиваются по степени замедления; подготовка закона времени видна всем (рябь экрана); застывшие снаряды видны как застывшие.
- [ ] **Интерфейс героя:** бумажная кукла (4 зоны), здоровье, лорный ресурс, температура, влажность, кнопки законов с перезарядкой, текущий план (список действий).
- [ ] **Подсказка «не подействует»:** при прицеливании закона на сущность, на которую он по меткам не действует, курсор показывает это.
- [ ] **Журнал событий** на экране: последние события по-русски (переиспользовать форматирование из `tools/sim`). Нужен для «понятно, почему я проиграл».
- [ ] **Экран победы/поражения** при срабатывании условия победы.

### 3. Команды

- [ ] `pnpm dev` — запуск клиента локально.
- [ ] `pnpm build` — сборка клиента; входит в `pnpm check`.

### 4. Отчёт

- [ ] `docs/dev/reports/<дата>-stage-2.md` по шаблону из [workflow.md](workflow.md). Отдельный пункт: **что на экране читается плохо** (кажется непонятным или сливается).

## Готово, когда

- `pnpm install && pnpm check` — зелёное.
- `pnpm dev`: можно выбрать героев, дойти до врага, убить его, сломать трон и увидеть экран победы.
- Хронистом и Тенью можно собрать «стену ножей» и увидеть глазами, как ножи висят и потом летят.
- Мясником можно сломать врагу ноги и увидеть кровавый след.
- Все допущения записаны в [decisions.md](decisions.md), отчёт написан.

## Вне этапа 2

Бот, сеть, прокачка и мутации, кампания и её цели, звук, спрайты и анимации, линии и крипы.
