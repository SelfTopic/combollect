# 11. Баланс

Бесконечная комбинаторика — главный риск игры. Баланс должен держаться на **правилах**, а не на ручной подкрутке каждого закона.

## Инструменты баланса

### 1. Только лорные рычаги
См. [01-lore-integrity.md](01-lore-integrity.md), правило 4: цена, условие, подготовка, ресурс, носитель, метки целей. Масштаб явления никогда не урезается до нелепого.

### 2. Бюджет мощности [предложение]
Каждому закону и каждому шагу прокачки присваивается «вес». Примерная формула:

```
мощность = сила × длительность × охват × (1 / перезарядка)
охват:   одна цель = 1, зона = 3, вся карта = 10
```

Цена закона (ресурс + лорная цена + подготовка) должна расти вместе с мощностью. Если игрок прокачивает остановку времени до 4 секунд, её перезарядка и старение растут автоматически по формуле, а не вручную.

### 3. Правило двух ответов
У каждого закона минимум **два способа противодействия из разных уровней абстракции**. Записывается в поле «Противодействие» каталога. Если ответ только один — закон не принимается.

### 4. Бюджет потери контроля [предложение]
Сумма секунд, в которые игрок не может действовать полноценно, ограничена. Например: не более 25% времени боя. Если команда собирает слишком много контроля, это видно в симуляции.

### 5. Цена растёт со злоупотреблением
Лорные цены необратимы (старение, доза, шрамы на карте). Сила, применённая 10 раз, обходится гораздо дороже, чем применённая 2 раза. Это естественный ограничитель «спама».

### 6. Открытая информация
Все метки, мутации и прокачка любого героя видны всем (как армия в Heroes 3). Сильная стратегия, которую видно заранее, всегда можно контрить. Сильная скрытая — нет.

## Симуляция [предложение]

Ручной баланс невозможен при таком числе комбинаций. Поэтому с самого начала:

1. **Боты со случайными билдами.** Тысячи матчей бот против бота со случайным распределением очков и мутаций.
2. **Метрики:**
   - процент побед для каждой мутации и каждого закона;
   - процент побед для пар «закон A у меня — закон B у врага»;
   - средняя длительность потери контроля;
   - доля матчей, решённых одним глобальным законом.
3. **Сигналы тревоги:**
   - мутация с винрейтом > 58% или < 42% при достаточной выборке;
   - пара, где один закон побеждает почти всегда → проверить правило двух ответов;
   - «пустая» мутация, которую боты никогда не выбирают при оптимизации.
4. **Эволюционный поиск.** Генетический алгоритм ищет лучшие билды. Если находит один, который бьёт всё, это дыра в балансе.

Для этого симуляция с первого дня должна уметь работать **без графики и быстрее реального времени**.

## Известные риски

| Риск | Почему опасно | Чем закрыть |
|------|---------------|-------------|
| Команда из 5 «вне времени» | Остановка времени без минусов для своих | Мало героев с этой меткой, у всех тяжёлые слабости на нижних уровнях; противник видит драфт |
| Синтез + Складка | Перебросить взрыв прямо на базу | Подготовка синтеза видна; складка требует видимости обеих точек |
| Давление на героя с двумя травмами | Хронист становится беспомощным | Предметы на рассудок, союзник-поддержка, `Несгибаемая воля` как мутация |
| Бесплотные против физических команд | Полный иммунитет к 1–3 | Обязательная уязвимость наверху (свет, пространство) + драфт |
| «Тихая подготовка» как прокачка | Убивает читаемость | Подготовка глобальных законов не сокращается ниже порога (например, 1 с) |
