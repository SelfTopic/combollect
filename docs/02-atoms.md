# 02. Атомы мира

Всё в игре — **сущности**. Каждая сущность описывается тремя видами атомов:

| Вид | Что это | Меняется в матче? | Пример |
|-----|---------|-------------------|--------|
| **Метки** | Что сущность *есть* | Почти никогда | «Живой», «Есть конечности», «Вне времени» |
| **Состояния** | Что с сущностью *сейчас* | Постоянно | «Температура −12°», «Левая нога сломана», «Доза 40 бэр» |
| **Ресурсы** | Чем сущность расплачивается | Постоянно | Здоровье, лорный ресурс носителя |

Законы ([04-laws-catalog.md](04-laws-catalog.md)) читают **метки**, чтобы решить, действуют ли они на сущность, и меняют **состояния** и **ресурсы**.

---

## 1. Метки [предложение]

Метки сгруппированы по уровням абстракции. Сущность может иметь любое сочетание.

### Существование
| Метка | Значение | Кто обычно имеет |
|-------|----------|------------------|
| `Материальный` | Состоит из вещества, имеет массу | Почти все |
| `Бесплотный` | Нет вещества (дух, энергия, концепт) | Призраки, сущности-фундаменталы |
| `Концепт` | Существует как идея/закон, а не как объект | Редкие высшие сущности |

### Психика (уровень 0)
| Метка | Значение |
|-------|----------|
| `Разум` | Способен думать и воспринимать. Цель внушения и иллюзий |
| `Эмоции` | Способен испытывать страх, гнев. Цель давления |
| `Травма:<тип>` | Конкретная уязвимая точка психики: `Травма:Утрата`, `Травма:Смерть`, `Травма:Одиночество`, `Травма:Плен`, `Травма:Вина` |
| `Несгибаемая воля` | Психическое давление ослаблено |
| `Безразумный` | Нет ни разума, ни эмоций (голем, механизм). Полностью иммунен к уровню 0 |

### Тело (уровень 1)
| Метка | Значение |
|-------|----------|
| `Живой` | Есть биология: болеет, кровоточит, облучается |
| `Конечности` | Есть руки/ноги, которые можно повредить |
| `Мозг` | Есть ЦНС, которую можно повредить |
| `Кровь` | Может кровоточить |
| `Глаза` | Видит светом. Цель ослепления |
| `Дыхание` | Нуждается в воздухе. Цель удушья, ядовитых газов |
| `Регенерирующий` | Восстанавливает части тела естественным путём |

### Физика (уровни 2–4)
| Метка | Значение |
|-------|----------|
| `Масса:<лёгкая/средняя/тяжёлая/огромная>` | Насколько сложно сдвинуть |
| `Теплокровный` | Держит собственную температуру, страдает от мороза и жара |
| `Горючий` | Может гореть (дерево, ткань, плоть) |
| `Негорючий` | Камень, металл, лёд |
| `Проводник` | Проводит ток (металл; любая мокрая сущность временно) |
| `Изолятор` | Не проводит ток |

### Материя (уровень 5)
| Метка | Значение |
|-------|----------|
| `Атомная структура` | Подвержен радиации и распаду (всё материальное) |
| `Радиостойкий` | Накапливает дозу медленнее |

### Пространство и время (уровни 6–7)
| Метка | Значение |
|-------|----------|
| `В пространстве` | Подчиняется искажениям пространства (по умолчанию у всех) |
| `Многомерный` | Частично существует в других измерениях: искажения на него действуют слабо |
| `Во времени` | Подчиняется законам времени (по умолчанию у всех) |
| `Вне времени` | Не подчиняется изменениям течения времени. Движется в остановленном времени |
| `Якорь времени` | Нельзя «откатить» в прошлое состояние |

### Роль в матче (не лорные, служебные)
`Герой`, `Крип`, `Строение`, `Снаряд`, `Призыв`, `Местность`, `Нейтрал`.

## 2. Состояния [предложение]

Состояния — это числа или флаги, которые законы меняют. **Нет абстрактных «оглушений» и «замедлений»**: любой контроль — это следствие физического или психического состояния.

### Тело: «бумажная кукла»
У сущностей с меткой `Конечности` тело разбито на 4 зоны. У каждой зоны есть целостность 0–100%.

| Зона | Что даёт при 100% | Что происходит при повреждении |
|------|-------------------|-------------------------------|
| **Голова** | Точность, скорость каста | < 50%: каст медленнее; 0%: сотрясение, нельзя применять законы 1–2 секунды |
| **Торс** | Основа здоровья | Получает основной урон; 0% = смерть |
| **Руки** | Атака, применение законов, требующих жестов | < 50%: атака медленнее; сломаны: нельзя законы с жестом |
| **Ноги** | Скорость передвижения | < 50%: медленнее; сломаны обе: только ползком (30% скорости) |

> «Оглушение» в нашей игре — это сотрясение мозга (голова), «замедление» — это повреждённые ноги, обморожение или страх. У каждого контроля есть лорная причина, и поэтому у каждого есть лорное противодействие (лечение ног, согрев, воля).

### Температура
Число в градусах относительно нормы (0 = норма).
- −10…−30: обморожение, скорость снижается пропорционально.
- ниже −30: замерзание конечностей (зоны Руки/Ноги теряют целостность).
- +10…+30: ожоги, урон торсу.
- выше +30: горение (если `Горючий`), распространяется на соседей.

### Влажность
`Сухой` / `Мокрый` / `Промокший`. Мокрая сущность временно получает метку `Проводник`, хуже горит, быстрее замерзает.

### Рассудок (только с меткой `Разум`)
Число 0–100.
- < 60: видит иллюзии как реальные.
- < 30: страх. Движение к источнику давления на 40% медленнее, от источника — на 20% быстрее. Игрок всё ещё управляет героем.
- 0: срыв. Нельзя применять законы уровня 5+ (нужна концентрация) 3 секунды.

### Кровопотеря (с меткой `Кровь`)
Открытая рана теряет здоровье **при движении** (сердце качает кровь). Стоя на месте, теряешь меньше. Оставляет кровавый след на карте (виден врагам).

### Доза облучения (с меткой `Живой`)
Накапливается, почти не выводится. Пороги:
- 100: максимальное здоровье −10%;
- 300: регенерация отключена;
- 600: торс теряет целостность со временем.
Лечится только специальными законами или на базе.

### Течение времени
Множитель часов сущности, см. [06-time-system.md](06-time-system.md). 1.0 — норма, 0 — остановлено.

### Пространственный сдвиг
Флаг: находится ли сущность в искажённой зоне. Расстояния внутри неё другие.

## 3. Ресурсы

| Ресурс | Что это |
|--------|---------|
| **Здоровье** | Общая жизнеспособность. Связано с целостностью торса |
| **Лорный ресурс носителя** | У каждого героя свой, объяснённый лором: «Хронос» у повелителя времени, «Топливо» у ядерщика, «Воля» у менталиста. Вместо универсальной маны |
| **Опыт и золото** | Для прокачки, см. [08-progression.md](08-progression.md) |

> Почему не универсальная мана: «мана» — абстракция без лора. Если повелитель времени тратит собственное время жизни, а ядерщик — топливо, то и способы их ограничить разные: ядерщику можно не дать дозаправиться, а повелителю времени нечем помочь.

## Пример полного описания сущности

**Лесной волк (крип-нейтрал)**
- Метки: `Материальный`, `Живой`, `Конечности`, `Мозг`, `Кровь`, `Глаза`, `Дыхание`, `Эмоции` (разума нет, но страх испытывает), `Масса:средняя`, `Теплокровный`, `Горючий`, `Атомная структура`, `В пространстве`, `Во времени`, `Нейтрал`.
- Состояния: все зоны 100%, температура 0, сухой.
- Что на него действует: страх (да), внушение (нет, нет разума), переломы (да), горение (да), молния (только если мокрый), радиация (да), остановка времени (да).
