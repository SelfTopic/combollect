# 08. Прокачка

Прокачка — главный «кроссворд» игры. Именно здесь игрок решает, каким путём будет побеждать в этом матче.

## Два вида улучшений [решено в общем, детали — предложение]

### Количественные — «насколько»
Ты перечислил: длительность, урон, частота, кулдауны, дальность применения, скорость возрождения, пассивная регенерация, вампиризм и т.д.

Они делятся на два уровня:

**Параметры закона** (улучшаются отдельно для каждого закона героя):

| Параметр | Что меняет |
|----------|-----------|
| Сила | Насколько сильно меняется состояние (градусы, рассудок, множитель часов) |
| Длительность | Сколько длится эффект |
| Перезарядка | Как часто можно применять |
| Дальность | С какого расстояния |
| Радиус | Размер зоны (для зональных) |
| Стоимость | Сколько ресурса тратится |
| Подготовка | Насколько быстрее готовится (риск: менее заметно = менее честно, см. [11-balance.md](11-balance.md)) |
| Цена | Снижение лорной цены (старения, дозы) |
| След | Длительность и сила следа на карте |

**Параметры героя** (общие):

| Параметр | Что меняет |
|----------|-----------|
| Здоровье | Максимум |
| Регенерация | Пассивное восстановление |
| Восстановление ресурса | Скорость |
| Скорость возрождения | Как быстро возвращается после смерти |
| Скорость передвижения | |
| Прочность зон тела | Сопротивление переломам |
| Вампиризм | Лечение от нанесённого урона (только если лор героя это позволяет) |

### Качественные — «как» (мутации)
Количественные улучшения меняют числа. **Новые пути открывают мутации**, которые меняют форму закона. Без них прокачка была бы линейной.

| Тип мутации | Пример |
|-------------|--------|
| **Масштаб** | Цель → зона → вся карта |
| **Избирательность** | Все → только враги (дорого: противоречит «слепой силе») |
| **След** | Мгновенный эффект → оставляет постоянную зону |
| **Наследование** | Снаряды наследуют метку носителя (`Вне времени`) |
| **Инверсия** | Отталкивание → притяжение |
| **Триггер** | Применяется вручную → срабатывает сам при условии (при смерти, при низком HP) |
| **Продолжение** | Эффект не прекращается при разрыве канала |
| **Перенос** | Закон можно передать союзнику на время |

## Экономика прокачки [предложение]

- **Опыт → уровни героя (1–25).** Каждый уровень даёт 1 очко прокачки.
- **Очки** тратятся на количественные улучшения: 1 очко = 1 шаг одного параметра.
- **Мутации** открываются только на уровнях 6, 12, 18, 24: на каждом из них герой выбирает **одну** мутацию из 3–4 доступных для его законов. Это важнейшие решения матча.
- **Золото** — второй ресурс, тратится на **предметы-носители меток** (см. ниже).
- Очки **нельзя перераспределить** в матче. Решение окончательно, как в Heroes 3.

### Предметы-носители меток [предложение, обсуждается]
Предметы не дают «+20 урона». Они **меняют метки** героя, и это тоже лорно:
- **Резиновый плащ** — даёт `Изолятор`.
- **Свинцовый амулет** — даёт `Радиостойкий`.
- **Песочные часы из остановленного боя** — даёт `Вне времени` на 1 применение чужого закона (очень дорого).
- **Маска без лица** — убирает `Глаза` на 5 с (иммунитет к вспышке, но слепота).
- **Ледяная кровь** — убирает `Теплокровный`, но делает уязвимым к огню.

Так любой герой может «подстроиться» под законы врагов, и драфт не решает всё.

## Почему путей действительно бесконечно много

Возьмём одного Хрониста:
- ~10 параметров × 25 очков → огромное число распределений;
- 4 мутации из 3–4 вариантов → 81–256 сочетаний;
- ×5 союзников со своими путями;
- ×5 врагов со своими путями, на которые нужно отвечать;
- ×состояние карты (следы, разрушения).

Но главное не число, а то, что **правильный ответ каждый раз разный**: против команды с Мясником Хронисту выгоднее качать прочность рук, против команды с Эхо — сопротивление давлению, рядом с Тенью-без-часов — длительность замедления.

## Ограничение: интерфейс прокачки

- Количественное улучшение: одна кнопка (`+` у параметра), можно в бою.
- Мутация: модальный выбор из 3–4 карточек, лучше вне боя. Игра не ставится на паузу, поэтому рисковать можно.
- Билд соперника **виден** (открытая информация, как армия в Heroes 3): наведи на героя, увидишь его мутации и метки. Количественные очки — тоже видны. Скрывать нечего, кроссворд от этого только глубже.
