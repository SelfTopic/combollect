# Этап 1: ядро симуляции

**Вопрос этапа:** работают ли атомы и законы системно, без ручных исключений? (См. [../14-prototype-plan.md](../14-prototype-plan.md).)

Графики нет. Результат — пакеты `core` и `content`, тесты и CLI, который прокручивает сценарий и печатает журнал событий.

## Что сделать

### 1. Каркас репозитория
- [ ] pnpm workspaces: `packages/core`, `packages/content`, `tools/sim`.
- [ ] Общий `tsconfig.base.json` (настройки из [code-style.md](code-style.md)), Biome, Vitest.
- [ ] Скрипты в корневом `package.json`: `test`, `test:watch`, `typecheck`, `lint`, `check`, `sim`.
- [ ] `.gitignore` (node_modules, dist, coverage).

### 2. `core`: атомы
- [ ] Реестр меток (`TagId`) из [glossary.md](glossary.md).
- [ ] `Entity`: метки, состояния, ресурсы, позиция, скорость, часы, законы, план.
- [ ] Состояния этапа 1: температура, влажность (`dry`/`wet`/`soaked`), зоны тела (`head`, `torso`, `arms`, `legs`, 0–100%), здоровье. Подробности — [../02-atoms.md](../02-atoms.md).
- [ ] `TagQuery` и функция `affects(law, entity)`.
- [ ] Сид-RNG (`world.rng`).
- [ ] Журнал событий с причиной каждого изменения.

### 3. `core`: время
- [ ] `Clock`, `TimeField`, `clockSystem` по [architecture.md](architecture.md) и [../06-time-system.md](../06-time-system.md).
- [ ] Множители перемножаются; `OutOfTime` игнорирует чужие поля; длительность поля — в часах носителя.
- [ ] Остановка (`rate = 0`) должна работать на уровне ядра, даже если закона остановки ещё нет (проверяется тестом с полем `×0`).
- [ ] Удар по остановленной сущности копится и применяется при возобновлении ([../06-time-system.md](../06-time-system.md), правило 2).

### 4. `core`: карта
- [ ] `Grid` из клеток: поверхность (`ground`, `grass`, `stone`, `water`, `ice`, `scorched`), температура, влажность.
- [ ] Сущность на клетке воды становится мокрой; лёд уменьшает трение.

### 5. `core`: системы
Порядок — как в [architecture.md](architecture.md). На этапе 1 нужны: `clock`, `plan`, `law`, `movement`, `projectile`, `thermal`, `wetness`, `conduction`, `body`, `trace`, `death`.

### 6. `content`: 6 законов
По каталогу [../04-laws-catalog.md](../04-laws-catalog.md):
- [ ] L2-01 Импульс (отбрасывание обратно массе; удар о камень — урон).
- [ ] L2-02 Бросок (снаряд — отдельная сущность `Material`, `Projectile`, `InTime`).
- [ ] L3-01 Пламя (температура, горение `Flammable`, распространение, выжженная земля).
- [ ] L3-02 Стужа (температура, лёд из воды, обморожение).
- [ ] L4-01 Разряд (ток по графу проводников в радиусе 150, мокрые = проводники, бьёт и своих).
- [ ] L7-01 Замедление времени (глобальное поле ×0.25 для `InTime`, подготовка 1.5 с, старение носителя).

Плюс базовая атака как закон механики ([../04-laws-catalog.md](../04-laws-catalog.md), «Базовая атака — тоже закон»).

### 7. `content`: тестовые существа
Без полноценных героев, только наборы меток для тестов: «человек», «человек вне времени», «волк», «каменный голем» (`Mindless`, `Nonflammable`, `Mass:Huge`), «дерево».

### 8. Тесты
По [testing.md](testing.md). Обязательный минимум — все строки таблицы [../05-interactions.md](../05-interactions.md), которые касаются законов этапа 1:
- [ ] Мокрый + Разряд: ток бьёт всех в луже, включая союзников.
- [ ] Стужа + Лужа: лёд не проводит ток.
- [ ] Пламя + Лёд: лёд тает в воду.
- [ ] Пламя + Мокрый: сначала высыхание, потом нагрев.
- [ ] Импульс + Лёд: отбрасывание вдвое дальше.
- [ ] Импульс + Камень: урон от удара.
- [ ] Замедление: снаряд, огонь, перезарядки, движение — ×0.25; `OutOfTime` — ×1.
- [ ] Остановка (поле ×0): снаряд застывает, покинув руку носителя вне времени; удар по остановленному копится.
- [ ] План: действия, отданные во время остановки, выполняются по порядку после возобновления; невозможное пропускается.
- [ ] Детерминизм: сценарий дважды с одним сидом → одинаковый журнал.

### 9. `tools/sim`
- [ ] `pnpm sim <сценарий>` запускает сценарий из `tools/sim/scenarios/` и печатает журнал событий в читаемом виде по-русски.
- [ ] Минимум 2 сценария: «Лужа и молния» и «Стена ножей» (человек вне времени + поле ×0 + броски, см. [../12-example-builds.md](../12-example-builds.md)).

### 10. Отчёт
- [ ] `docs/dev/reports/<дата>-stage-1.md` по шаблону из [workflow.md](workflow.md).

## Готово, когда

- `pnpm install && pnpm check` — зелёное.
- `pnpm sim knife-wall` печатает понятный журнал, где видно, как ножи застывают и потом одновременно летят.
- Все допущения записаны в [decisions.md](decisions.md).
- Отчёт написан.

## Вне этапа 1

Графика, сеть, герои целиком, прокачка и мутации, законы уровней 0, 1, 5, 6, психика, радиация.
