# 09. Карта и её память

Карта — не декорация, а **сущность, подчиняющаяся тем же законам**. Ты сформулировал прокачку как «влияние лорных сил на карту» — значит, карта должна это влияние помнить.

## Карта как сетка клеток [предложение]

Карта разбита на клетки (например, 32×32 единицы). У каждой клетки есть состояния, аналогичные состояниям сущностей:

| Состояние клетки | Значения | Что меняет |
|------------------|----------|-----------|
| Тип поверхности | земля, трава, камень, вода, лёд, песок, выжженная | Горючесть, проводимость, трение |
| Температура | число | Обжигает/морозит тех, кто стоит |
| Влажность | сухо / мокро / вода | Делает стоящих мокрыми |
| Радиация | число | Доза для стоящих, медленно распадается |
| Искажение | множитель расстояния | Длина пути |
| Временной шрам | флаг + сила | Течение времени слегка неровное |
| Кровь | след + направление | Видно, куда ушёл раненый |

## Объекты карты (тоже сущности с метками)

| Объект | Метки | Как взаимодействует |
|--------|-------|---------------------|
| Дерево | `Материальный`, `Горючий`, `Живой` | Горит и исчезает навсегда (до конца матча), открывает проходы и видимость |
| Камень | `Материальный`, `Негорючий`, `Масса:огромная` | Укрытие от давления (разрывает видимость), стена для импульса |
| Озеро/река | Клетки «вода» | Мокрые → проводники; замерзает в лёд |
| Плавильня | `Строение` | Источник «Топлива» Солнечника. Стратегическая точка |
| Башня | `Строение`, `Материальный`, `Атомная структура`, `Во времени`, `Безразумный` | Останавливается во времени! Иммунна к психике. Разрушается радиацией |
| Крипы | `Живой`, `Эмоции`, `Во времени` | Подвержены страху, огню, времени. Безразумны для иллюзий |

## Следы законов

Каждый закон в каталоге имеет поле «След». Следы — главный механизм «карта помнит»:

| След | Источник | Длительность | Стратегическое значение |
|------|----------|--------------|-------------------------|
| Выжженная земля | Пламя | 120 с | Нельзя поджечь снова. Лес, сгоревший раз, не горит |
| Сгоревший лес | Пламя по деревьям | **до конца матча** | Новые проходы, потеря укрытий |
| Лёд | Стужа | 90 с | Скольжение, усиление импульса |
| Заражённая зона | Облучение, Синтез | 180–300 с | Перекрывает маршруты, вынуждает обходить |
| Кратер | Синтез | **до конца матча** | Новая геометрия: низина, где собирается вода |
| Шрам пространства | Искажение, Складка | 60 с | Неровные расстояния |
| Временной шрам | Законы времени | 30 с | Слабое замедление ×0.9 в точке |
| Кровавый след | Кровотечение | 60 с | Охота на раненых |

**Постоянные следы** (сгоревший лес, кратер) — то, что делает каждый матч уникальным к 30-й минуте. Их должно быть немного, и каждый должен менять стратегию.

## Структура карты [решено]

- **Прототип: 1×1.** Одна линия, две башни на сторону, лес по бокам, одно озеро, одна плавильня в центре.
- **Цель: 5×5.** Такое количество законов требует в команде самых разных существ: лекарей, танков, высших сущностей, научных существ, големов. Им всем нужно место.

Ключевое требование к любой карте: **на ней должны быть все типы поверхностей**, чтобы каждый закон имел, с чем взаимодействовать.
