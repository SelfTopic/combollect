# Combollect

MOBA, в которой герои владеют лорными законами мира (от психики до времени), и законы строго действуют так, как описаны в лоре. Автор — геймдизайнер проекта, общается по-русски.

## Где что

- `docs/` — дизайн игры. Начинать с `docs/README.md`.
- `docs/dev/` — техника: стек, архитектура, правила кода, порядок работы. Начинать с `docs/dev/README.md`.
- Текущее задание — `docs/dev/stage-2.md`. Этап 1 сделан, его отчёт — в `docs/dev/reports/`.

## Команды

- `pnpm install` — установить зависимости
- `pnpm check` — типы + линтер + тесты; должно быть зелёным перед каждым коммитом
- `pnpm test` — только тесты
- `pnpm sim <сценарий>` — прогнать сценарий без графики и вывести журнал событий
- `pnpm dev` — запустить клиент в браузере (с этапа 2)

## Жёсткие правила

1. **Лорная честность.** Никаких исключений «ради геймплея». Закон действует на всех с подходящими метками, включая союзников и носителя. См. `docs/01-lore-integrity.md`.
2. **Ядро (`packages/core`) — без окружения и детерминированное:** без DOM/Node API, без `Math.random`, без `Date.now`. Только `world.rng` и локальные часы.
3. **Все таймеры — в локальном времени сущности** (`clock.rate`). См. `docs/06-time-system.md`.
4. **Законы не знают друг о друге** и проверяют только метки и состояния, никогда — идентичность героя или закона. Особые взаимодействия — только в `content/interactions.ts`.
5. **Код — по-английски по словарю `docs/dev/glossary.md`, комментарии и тексты — по-русски.**
6. **Дизайн-документы (`docs/*.md` вне `dev/`) не переписывать.** Неясность в дизайне → лорно-честное допущение в `docs/dev/decisions.md` с пометкой `ДОПУЩЕНИЕ`.
7. В конце работы — отчёт в `docs/dev/reports/` по шаблону из `docs/dev/workflow.md`.
