# Тестирование

## Что тестируем обязательно

1. **Каждый закон:** на кого действует, на кого нет (метки), что меняет.
2. **Каждое взаимодействие** из таблицы [../05-interactions.md](../05-interactions.md), которое реализуемо на текущем этапе. Имя теста начинается с пары законов: `'Стужа + Разряд: замёрзшая лужа не проводит ток'`.
3. **Часы:** таймеры, движение, снаряды и перезарядки идут в локальном времени; `OutOfTime` не замедляется.
4. **Детерминизм:** один и тот же сценарий с одним сидом дважды → одинаковый журнал событий.
5. **Лорная честность:** закон бьёт своих и носителя, если у них есть подходящие метки.

## Как писать тесты

- Vitest. Тесты рядом с кодом или в `test/` пакета — как удобнее, но единообразно внутри пакета.
- Мир для теста строится хелпером: `createTestWorld({ seed, grid, entities })`.
- Время прокручивается хелпером: `runSeconds(world, 2.5)`.
- Проверять результат через состояния и **журнал событий**, а не через внутренние поля систем.
- Один тест — одно утверждение о мире. Имена тестов — по-русски, как фраза о правиле мира.

```ts
test('Замедление времени: снаряд во времени летит в 4 раза медленнее', () => { ... });
test('Замедление времени: сущность вне времени движется с обычной скоростью', () => { ... });
```

## Команды

- `pnpm test` — все тесты.
- `pnpm test:watch` — в режиме наблюдения.
- `pnpm typecheck` — проверка типов.
- `pnpm lint` — Biome.
- `pnpm check` — всё вместе. **Должно быть зелёным перед каждым коммитом.**
