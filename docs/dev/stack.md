# Стек

## Сейчас (этап 1)

| Что | Чем | Почему |
|-----|-----|--------|
| Язык | **TypeScript 5.x**, `strict: true` | Один язык для браузера, сервера, ботов и exe |
| Рантайм | **Node.js 24** (установлен у автора) | Тесты, симуляция, позже сервер |
| Пакетный менеджер | **pnpm** (workspaces) | Монорепозиторий из нескольких пакетов |
| Модули | ESM (`"type": "module"`) | Стандарт |
| Тесты | **Vitest** | Быстрый, нативно TypeScript |
| Линтер и форматтер | **Biome** | Один инструмент вместо ESLint + Prettier |
| Запуск скриптов | **tsx** | Запуск `.ts` без сборки |
| Проверка типов | `tsc --noEmit` | |

## Ключевое требование к стеку

Пакет `core` (симуляция мира) — **чистый TypeScript без зависимостей от окружения**: ни DOM, ни Node API, ни файловой системы, ни сети. Он должен одинаково работать в браузере, на сервере, в ботах и в тестах. См. [architecture.md](architecture.md).

## Версии

Конкретные версии фиксируются в `package.json` и `pnpm-lock.yaml`. Обновлять зависимости — только отдельным коммитом с записью в [decisions.md](decisions.md), если обновление мажорное.
